MONK MODE

MonkMode is an open source deep-focus system built to eliminate distractions and make meaningful work the default—combining intentional friction, Screen Time-powered blocking, commitment rituals, and accountability into one disciplined workflow.

How it works

Commitment through friction

MonkMode does not rely on willpower. It builds deliberate barriers between you and distraction.

01

Set a session

Choose a timed or multi-day focus session. Commit to deep work with zero exceptions.

02

Block distractions

Guided iOS Screen Time setup blocks apps and websites—no paid developer account required.

03

Stay accountable

Track streaks, run recovery missions, and bring friends into friend lock + accountability flows.

Features

Built for discipline

Everything you need to enforce deep work and protect your attention.

▪

Timed & multi-day sessions

Run focus blocks that last minutes or days. Your phone stays locked until the session ends.

▪

Screen Time blocking

Optional native enforcement via FamilyControls/ManagedSettings—works without a paid Apple Developer account.

▪

Friend lock

Accountability flows let a trusted friend hold the key to your blocked apps.

▪

Stats & streaks

View session history, streaks, and recovery missions to measure your discipline over time.

▪

Website blocklist

Block or allow specific websites with shareable, exportable lists for deep work.

▪

Webhooks

Optional outbound webhooks for session events so you can integrate MonkMode into your own stack.

Open source

No paywall. No subscription.

How to run

Clone the repo, install dependencies, and start Expo. A real device is required for iOS Screen Time integration.

git clone https://github.com/yuvaang13/MonkMode-app
cd MonkMode-app/monkmode/monkmode-v3
npm install
npm run start

Status

Active development. Native iOS modules handle Screen Time and device integrations. Not yet published to the App Store.
